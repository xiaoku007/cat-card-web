# 既事已定 · 猫牌

一款 **UNO × 薛定谔的猫 × 左轮** 的卡牌游戏网页版，支持 **2~4 人 P2P 联机**（WebRTC，无需服务器即可远程对战）。

- 🎴 105 张牌（93 张主牌 + 12 张猫牌），完整实现：翻猫跳过、猜牌/反猜、保护/禁言/互换/观看 等全部规则
- 🔁 可选规则（房主在大厅开关，默认全部开启）：2/3 人 4 猫牌、额外猫牌（手牌猫/盖猫续命）、保护解除他人、淘汰制玩法
- 🌐 P2P 联机：PeerJS 信令 + 星型拓扑，支持断线自动重连与主机掉线迁移
- ✨ 杀戮尖塔风格动效：扇形手牌、悬停浮起、飞牌、翻牌

## 快速开始

### 方式一：直接玩（远程联机）

把本项目部署到任意静态托管（如 GitHub Pages / Netlify / Vercel），或本地起一个静态服务器，
玩家直接打开链接即可建房对战（信令走 PeerJS 官方云服务器，需要联网）。

### 方式二：本地 / 局域网

```bash
node server.js          # 零依赖静态服务器，默认 http://0.0.0.0:5500
```

- 房主打开 `http://localhost:5500`，输入昵称，点「创建房间」
- 其他玩家打开 `http://<房主局域网IP>:5500?room=<房间码>`（房主可直接点「复制链接」发送）

> 局域网联机默认仍使用 PeerJS 官方云信令（需联网）。
> **完全离线** 的局域网对战：其中一台机器先启动本地信令服务器（`npx peerjs --port 9000`），
> 然后所有玩家用 `http://<IP>:5500?room=<码>&signal=<IP>:9000` 访问。

### 远程联机（公网）

P2P 数据直连不经过服务器，信号（信令）默认走官方云，因此：

1. 推到 GitHub 后在仓库 Settings → Pages 开启托管，获得公网地址；
2. 或本地跑 `node server.js` 后用 [cloudflared](https://developers.cloudflare.com/cloudflare-one/connections/connect-networks/) 隧道临时暴露：
   `cloudflared tunnel --url http://localhost:5500`，把生成的 https 地址分享给朋友即可。

## 规则开关（大厅可选，默认关闭）

| 开关 | 效果 |
| --- | --- |
| 2/3 人时每人 4 张猫牌 | 2/3 人局改为每人 4 张猫牌 |
| 额外猫牌规则 | 2/3 人局每人手牌中多 1 张猫牌；己方有翻开的猫牌时可在回合中让下家摸 2 张并把这只猫盖回去续命；手牌猫可被「互换」「观看」指定 |
| 保护牌可解除他人保护 | 「保护」可打在他人已保护的猫牌上以解除保护 |
| 淘汰制玩法 | 有人淘汰立刻重开一局，被淘汰者出局；上一局用猜牌淘汰过对手的玩家初始手牌 +1 |

## 玩法速览

- 每人 3 张（可选 4 张）猫牌盖置排开，初始手牌 8 张
- 按出牌方向轮流行动：上家出**点数牌** → 打更小的同白点数 / 更大的同黑点数 / 同色功能牌；上家出**功能牌** → 打同色牌；**万能牌**随时可出并自定义颜色点数
- 无法/不愿出牌 → 翻开自己一张猫牌，摸其点数张牌并跳过；3 张猫牌全翻开即淘汰
- **猜牌**：弃置总和严格为 5 的点数牌，依次报出对方所有未翻开猫牌的颜色，全中对方淘汰（自己补牌至 5 张），猜错对方可弃 1 张**反猜**
- 有玩家淘汰时，其余未被禁言的玩家各摸 1 张；最后存活者获胜

### 目录结构

```
index.html        页面入口
css/style.css     全部样式（桌面/卡牌/动效）
assets/cards/     卡牌美术图（由「导出」文件夹缩放规范化而来，320px 宽）

js/cards.js       牌组定义与出牌合法性
js/rules.js       纯规则引擎（状态机、效果、猜牌/反猜、可选规则）
js/net.js         P2P 网络层（房间、信令、心跳、断线重连、主机迁移）
js/ui.js          大厅 UI
js/gameui.js      游戏桌面 UI 与动效
js/main.js        入口装配
server.js         零依赖静态服务器（局域网用）
tests.mjs         规则引擎自测
```

### 网络架构说明

- 房主为**权威主机**，客户端全部直连主机（星型拓扑）
- 卡牌图片使用 **IndexedDB 本地缓存**：首次加载后写入浏览器本地，之后不用再重复下载（本地服务器同时下发 immutable 缓存头）
- 客户端掉线 15 秒标记断线、75 秒自动移出对局；断线玩家带会话凭据自动重连
- 主机掉线时，剩余玩家中座位号最小者自动接任主机（确定性 ID 重连），对局不中断
- 兼容性兜底：内置 Google STUN + OpenRelay TURN；企业内网不互通时可在局域网部署本地信令服务器
- ⚠ 轻量反作弊说明：为支持主机迁移，完整状态会同步到各客户端，由界面过滤隐藏信息（熟人局足够；若需要强防作弊需改为服务器权威部署）
